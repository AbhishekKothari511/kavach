# Campus Event Management System\n\nA full‑stack platform for campus event organizers and students.\n\n## Features\n- Organizers can create, edit, and manage events.\n- Students can browse events, search, and register online.\n- JWT based authentication with role‑based access (admin, organizer, student).\n- PostgreSQL schema with seat limits to prevent over‑registration.\n- Responsive UI built with React, Tailwind CSS, and a dashboard for tracking registrations.\n\n## Tech Stack\n- **Frontend**: React.js (Vite), Tailwind CSS\n- **Backend**: Node.js, Express.js, JWT\n- **Database**: PostgreSQL\n\n## Getting Started\n\n```bash\n# Clone the repo\ngit clone https://github.com/AbhishekKothari511/campus-event-management.git\ncd campus-event-management\n\n# Backend setup\ncd backend\nnpm install\ncp .env.example .env   # configure DB connection and JWT secret\nnpm run dev   # start Express server\n\n# Frontend setup\ncd ../frontend\nnpm install\nnpm run dev   # start Vite dev server\n```\n\n---\n\n*Project description taken from the user’s resume entry.*
